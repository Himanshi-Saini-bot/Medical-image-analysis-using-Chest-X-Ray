# Medical-image-analysis-using-Chest-X-Ray

Modedl file is not included due to large size, download trained model from here :- https://drive.google.com/drive/folders/12fS2z0Z0gkPMAppsr3aC6NWELQjqqsPw?usp=drive_link


Download dataset from here :- https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia

Features 
- Deep Learning based Pneumonia Detection
- Chest X-ray Image Classification
- CNN Model Implementation
- Real-time Prediction

#Tech Stack
- Python
- TensorFlow / Keras
- Flask
- NumPy, Pandas, Matplotlib

  
#How to Run
1. Clone the repository
2. Install requirements:
   pip install -r requirements.txt
3. Download trained model from the link provided
4. Run:
   python app.py
